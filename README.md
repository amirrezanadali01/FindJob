# FindJob 💼

A Flutter-based job search and recruitment application.

## About the Project

FindJob is a mobile application designed to connect job seekers with employers through an interactive and user-friendly experience.

## Features

- Animated onboarding screens
- Choose between finding a job or hiring employees
- Interactive task cards with dismiss animations
- Detailed user profile screen
- Display professional skills and experience
- Smooth animations and transitions
- Responsive user interface

## Tech Stack

- **Framework:** Flutter
- **Language:** Dart
- **Responsive UI:** sizer
- **Animations:** Flutter Animation Framework

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/amirrezanadali01/FindJob.git
   ```

2. Navigate to the project directory:

   ```bash
   cd findjob
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
